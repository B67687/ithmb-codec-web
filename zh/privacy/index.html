01

你的文件

解码器在浏览器里运行，开源的 ithmb-core（在新标签页打开） 库在你的设备上读取文件。解码器不上传任何文件，网站也不保留你的文件副本。浏览器里只保存语言和浅色/深色主题设置，这些值不会发送给我们。

02

我们不会做的事

  • 没有账号，也不用登录。
  • 本站不设置自己的 Cookie，也没有第三方跟踪器。
  • 没有统计脚本，也不投放广告。
  • 解码器不上传、也不扫描文件。
  • 我们不会出售你的数据，也不会把它用于广告共享。

解码出问题？到 GitHub（在新标签页打开） 提 issue，写清说明；能复现的话，请用最小化的合成样本。不要在公开 issue 里附个人照片或你自己的 .ithmb 文件：issue 是公开的，也能被搜到。需要私下提供文件，请用 私密报告通道（在新标签页打开）。

03

谁在负责

本站由独立开发者 Nami 维护（不是公司）。

网站或解码问题，请到 codec 仓库（在新标签页打开） 提 issue；安全或隐私问题，请走那里的 私密报告通道（在新标签页打开），不要开公开 issue。提交隐私请求时，请在标题里写“privacy”；这条通道是私密的。用不了 GitHub 的话，可以开一个不含个人信息的公开 issue，请我们提供其他方式。对本网站来说，就只有这两条联系渠道。

我们不会另外保存一份联系记录。GitHub 会按其条款保存 issue 和 advisory：公开 issue 会一直公开，advisory 在解决后也可能保留。请不要在公开 issue 里放个人数据。

04

托管、用途和法律依据

本站托管在 Cloudflare Pages，Cloudflare, Inc.（在新标签页打开） 处理访问请求的基本数据。

Cloudflare 会看到你的 IP 地址、请求的网址、浏览器/User-Agent 信息和访问时间。这些数据用于提供网页、保障网站安全和排查传输错误。

在欧盟或英国法律适用时，我们的法律依据是运营这个免费公开网站的正当利益（GDPR 第 6(1)(f) 条，英国 GDPR 对应条款）。你可以随时反对这种处理，详见“你的权利”。我们不依赖你的同意，因此没有同意弹窗。

Cloudflare 还可能收集网络错误报告（NEL）。我们不会收到这些报告，也不会用它们识别你的身份。

Cloudflare, Inc. 位于美国，请求数据可能会在欧盟经济区或英国以外处理。在需要时，Cloudflare 的数据处理附录（包括欧盟标准合同条款和英国附录）覆盖这些传输。GitHub 按其自身条款处理 issue 和 advisory 内容。

我们不添加统计、广告或跟踪脚本。Cloudflare 会向我们提供汇总的托管指标；如果它对请求发起验证，可能设置必要的安全 Cookie。详见 Cloudflare 的 隐私政策（在新标签页打开）。

05

数据保留

  • 我们不保存应用数据，也不保存应用日志：没有上传的文件、解码后的图片或账号。
  • Cloudflare 按其保留期保存托管请求数据；见上方的 Cloudflare 隐私政策。我们不会把这些数据复制到自己的系统。
  • 语言和主题设置保存在 localStorage 中，直到你清除本站数据或浏览器自行清除。这些设置不会发送给我们。
06

你的权利

在欧洲经济区（EEA）、英国或类似地区，你可以要求查看、更正、删除、限制处理、反对处理，也可以要求数据可携带。要行使这些权利（包括反对权），请使用第 03 节的联系渠道。

我们不保存访客数据库、统计画像或你的文件副本。Cloudflare 掌握的数据，我们不保留可按访客查询的请求日志，因此可能无法从请求中识别你。我们仍会回复，并说明能做什么、不能做什么。

你可以向我们投诉，也可以直接向当地监管机构投诉。英国的监管机构是 ICO。

我们不会出售你的数据，不会把它用于广告共享，也不会对你做用户画像。作为网站安全的一部分，Cloudflare 可能自动验证疑似机器人流量。
