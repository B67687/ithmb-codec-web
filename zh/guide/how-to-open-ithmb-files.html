怎么打开 .ithmb 文件

.ithmb 是 Apple 设备在 iTunes 同步照片和专辑封面时生成的缩略图缓存。旧 iPod、iPhone 的 PhotoData 文件夹里就有，普通看图软件打不开。这份指南讲怎么把里面的图取出来。

操作路径

  1. 1 设备iPod 或 iPhone
  2. 2 PhotoData复制到电脑
  3. 3 浏览器解码 .ithmb

不用安装，不用账号。文件始终留在你的电脑上。

先说清楚

网页版能打开什么：文件里直接带图像数据的 .ithmb 和 .ipm。从 iPod 的 PhotoData 复制出来的文件里，有些是原始缩略图，必须配合旁边的 PhotoDB 或 ArtworkDB 数据库才能解析，网页版不会解析这些数据库。

数据库文件用项目的桌面命令行工具（ithmb --open）打开。有些 ArtworkDB 文件把图像数据放在单独的 .ithmb 里，这种情况还没完全支持，解出来可能不对。看着不对，就到 GitHub 提 issue，附上文件头或样本。拿到的都是缩略图，不是原始大图。

01 · 准备

开始之前

你需要什么

  • 能当磁盘用的 iPod（iPod Classic、Nano 等）和它的数据线。
  • Windows、Mac 或 Linux 电脑，并在 iTunes 或访达里启用“磁盘使用”。
  • iPhone 或 iPod Touch：得用备份或恢复工具，它们不能当磁盘挂载。

只复制，不要改动设备：别重命名、移动或删除设备上的文件，也别往设备里写东西。解码器只读取文件，不会修改设备上的文件。

文件在哪里

此电脑 → iPod → iPod_Control/Photos/

在 iTunes 里启用“磁盘使用”，然后在“此电脑”里找到 iPod，把 PhotoData 文件夹复制出来。

访达 → iPod → iPod_Control/Photos/

在“访达”里启用磁盘使用，再从 iPod 上把 PhotoData 文件夹复制出来。

挂载的 iPod → iPod_Control/Photos/

挂载 iPod 后，在文件管理器里打开 iPod_Control/Photos/，把 PhotoData 文件夹复制出来。

更老的机型，缩略图在 Photos/Thumbnails/ 里。想要专辑封面，把同一个文件夹里的 ArtworkDB 也复制出来。

02 · 背景

什么是 ITHMB 文件？

Apple 做 ITHMB（iThumbnail 的缩写），是为了把大量小缩略图装进一个文件，让设备不加载原图也能浏览照片库。有些 .ithmb 文件存的是原始像素，有些里面是一张 JPEG。这个格式从来没公开过，所以普通看图软件打不开。

这些文件一般在旧 iPod、iPhone 的 PhotoData 文件夹里，也可能在备份或数据恢复出的磁盘镜像里。从 iPod Photo、iPod Video 时代到最后一款 iPod Classic，还有初代 iPhone 和早期 iPod Touch，都用过这个格式。解码器也认 .ipm 文件。

实际会碰到三种文件：

  • F 前缀文件（如 F1019_1.ithmb）：Apple 自有格式的原始像素，开头是一个简短的格式编号。
  • T 前缀文件（如 T1024_1.ithmb）：里面是一张 JPEG。
  • PhotoDB 和 ArtworkDB：存放缩略图记录的数据库。图像数据可能在数据库里，也可能在单独的 .ithmb 里。
01

第一步

把文件复制出设备

连上设备，启用磁盘使用，把缩略图复制到电脑。这些文件只在设备上有。

iPod Classic 或 Nano：连上设备，在 Windows 的 iTunes 或 Mac 的访达里启用磁盘使用，然后把 PhotoData 文件夹从 iPod_Control/Photos/ 复制到电脑。

iPhone 和 iPod Touch 不能当磁盘挂载，文件只能从备份或恢复工具里取。不管用哪种方式，文件到了电脑上，解码器就能处理。

你需要什么

设备、数据线，以及 iTunes 或访达中已启用的“磁盘使用”。iPhone 要备份或恢复工具。

你会看到

一个 PhotoData 文件夹，里面是 .ithmb 文件。想要专辑封面，还有 ArtworkDB。

出问题怎么办

没有照片？iPod 存的是缩略图，不是原图。老机型看 Photos/Thumbnails/，iPhone 看备份。

02

第二步

打开解码器

解码器完全在浏览器里跑。不用安装，也不用账号。

用 Chrome、Firefox、Safari 或 Edge 打开 ithmb-codec.dev/zh/ithmb-decoder。Windows、macOS、Linux 和手机都能用。

你需要什么

较新的 Chrome、Firefox、Safari 或 Edge。其他现代浏览器多半也能用。

你会看到

解码器页面，中间的框可以拖文件进来。

出问题怎么办

换一个现代浏览器再试。Chrome、Firefox、Safari、Edge 都支持。

03

第三步

拖入文件，保存图片

一个文件一张图。选好格式存单张，或者整批打包。

一次拖一个或多个文件都行。每张图可以选 JPEG、PNG、BMP 或 WebP，也可以点“打包下载”把整批存成 ZIP。网页版单个文件最大 8 MB。

你需要什么

文件里直接带图像数据的 .ithmb 或 .ipm。限制：单个文件最大 8 MB，单次最多 200 个文件、合计 256 MB。生成的 ZIP 超过 100 MB 时会先请你确认。

你会看到

一个文件一张图，还有格式切换和“打包下载”按钮。

出问题怎么办

提示“未知格式”，一般是原始 PhotoData 条目或数据库文件。见疑难排查。

03 · 会得到什么

拿到的是什么

适合屏幕尺寸的缩略图

iPod 只存适合自身屏幕尺寸的缩略图，这样不加载原图也能浏览照片库。320 × 320 的缩略图，不会像你同步进去的原图那么清晰。

有些机型颜色更少

有些机型在缩略图缓存里压低了色彩精度。解出来的是设备上的文件，不是拿原图重新转的。

原图不在里面

这些是缩略图，不是原始照片。原图在你的照片库、备份，或者当初导入照片的地方。

04 · 出问题怎么办

疑难排查

打不开通常就两个原因：文件不是网页版支持的类型，或者复制的时候被截断了。

提示“未知格式”，或者格式编号是 0

文件里没有图像数据。PhotoData 里有些是原始缩略图，必须配合旁边的 PhotoDB 或 ArtworkDB 数据库才能解析，网页版不会解析这些数据库。数据库文件请用下面的桌面工具。

这是数据库文件，不是单张图片

它是 PhotoDB 或 ArtworkDB 数据库，里面有很多缩略图记录，不是一张图。用桌面命令行工具打开（ithmb --open PhotoDB）。有些 ArtworkDB 文件把图像数据放在单独的 .ithmb 里，这种情况还没完全支持。看着不对，就到 GitHub 提 issue，附上文件头或样本。

图片花屏、只显示一部分，或者直接解不开

文件可能被截断或损坏，也可能根本不是 .ithmb。从设备上重新复制一份，确认大小和原文件一致。

PhotoData 里没有照片

iPod 存的是缩略图，不是原图。文件夹是空的，可能当年同步时就没勾照片，或者文件在更老的 Photos/Thumbnails/ 路径下。iPhone、iPod Touch 去备份里找。

颜色不对

可能是这种编码还没被正确识别。到 GitHub 提 issue，附上文件头和样本，让项目看看这个文件。

还是卡住了？

欢迎提交 issue，并附上格式样本。到 GitHub（在新标签页打开） 上开一个 issue，我们会跟进。

网页版打不开的文件，可以用项目的桌面工具。ithmb 命令行工具用 ithmb --open PhotoDB（或 --open ArtworkDB）读数据库文件，把每个缩略图导出为 PNG。用法见 项目的操作指南（在新标签页打开）里。有些 ArtworkDB 文件把图像数据放在单独的 .ithmb 里，这种情况还在修，解出来可能不对。看着不对，就到 GitHub 提 issue，附上文件头或样本。注意 --open 后面跟的是数据库文件，不是文件夹。

05 · 问答

常见问题

可以一次转换多个 .ithmb 文件吗？

可以。把多个文件一起拖进解码器，它会全部处理。一个文件一张图，点“打包下载”可以把整批存成 ZIP。

文件会离开我的设备吗？

不会。解码就在浏览器里完成，文件不离开你的设备。隐私页有更详细的说明。

.ipm 文件也支持吗？

支持。解码器把 .ipm 当成普通 .ithmb 一样处理，读文件里的图像数据。

这个工具免费吗？

免费。不用账号，没有广告，也没有付费墙。网页版单个文件最大 8 MB，单次最多 200 个文件、合计 256 MB。生成的 ZIP 超过 100 MB 时会先请你确认。想支持这个项目，可以请作者喝杯咖啡（在新标签页打开）。

为什么 iPod 上 PhotoData 文件夹里的文件打不开？

PhotoData 里有些 .ithmb 是原始缩略图，文件里没有图像数据，得配合同一文件夹里的 PhotoDB 或 ArtworkDB 数据库才能解析，网页版不会解析这些数据库。数据库文件用桌面版命令行工具（ithmb --open PhotoDB）打开。有些 ArtworkDB 文件把图像数据放在单独的 .ithmb 里，这种情况还没完全支持，解出来可能不对。看着不对，就到 GitHub 提 issue，附上文件头或样本。

能找回原始照片吗？

不能。这些是设备按自身屏幕尺寸生成的缩略图。原图在你的照片库、备份，或者当初导入照片的相机、存储卡里。

一个文件只有一张图吗？

网页版一个文件显示一张图。有些原始文件里连着好几帧，网页版只显示第 1 帧，卡片上会标“第 1 帧，共 N 帧”。命令行工具可以用 ithmb --frame N 取出指定的帧。
